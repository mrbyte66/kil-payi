# Fontlar

Fredoka ve Nunito, SIL Open Font License 1.1 ile lisanslıdır (ücretsiz, uygulamaya gömülebilir).
Google Fonts'tan `node tools/fetch-fonts.mjs` ile indirilir; yalnızca latin ve latin-ext kümeleri (Türkçe karakterler dahil).

- Fredoka: https://fonts.google.com/specimen/Fredoka
- Nunito: https://fonts.google.com/specimen/Nunito
- Lisans: https://openfontlicense.org
